# 🎓 Scholarship Portal - Scholarship Management System

Real-time statistics & scholarship metrics powered by Flask & SQLite/MySQL.

## 🚀 Features

- **Dashboard Overview**: Metrics for Total Students, Scholarships, Applications, Pending, Approved, and Rejected.
- **Students Directory**: Manage student records, academic courses, and family income details.
- **Scholarships Directory**: Manage scholarship schemes, trust providers, award amounts, and deadlines.
- **Applications Directory**: Process scholarship applications with instant status updates (`Pending`, `Approved`, `Rejected`).
- **Interactive UI**: Custom styling matching academic scholarship portal designs with responsive tables and modals.

## 🛠️ Tech Stack

- **Backend**: Python 3, Flask, Flask-SQLAlchemy, SQLite
- **Frontend**: HTML5, Tailwind CSS, FontAwesome Icons

## 💻 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/pothireddynikhil-svg/scholarship-management-system.git
   cd scholarship-management-system
   ```

2. Install dependencies:
   ```bash
   pip install flask flask-sqlalchemy
   ```

3. Run the application:
   ```bash
   python app.py
   ```

4. Open "https://barnes-arrival-concord-americans.trycloudflare.com/" in your web browser.
